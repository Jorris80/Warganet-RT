LAYANAN YANG *TIDAK* DISERTAKAN
================================

Hal-hal berikut sengaja TIDAK ditanam di dalam aplikasi, karena ketentuannya
tidak mengizinkan pemakaian pada produk yang dijual tanpa perjanjian sendiri:

  - Ubin peta OpenStreetMap (tile.openstreetmap.org)
    Dijalankan sukarelawan. Kebijakannya melarang pengunduhan massal dan
    penyimpanan luring, serta menyatakan akses layanan komersial dapat
    dicabut sewaktu-waktu.

  - Citra Esri lewat server.arcgisonline.com
    Bukan basemap bebas pakai. Ketentuan Esri mensyaratkan langganan ArcGIS
    dan token yang sah.

  - Ubin OpenTopoMap
    Server sukarelawan dengan batasan serupa OpenStreetMap.

Sebagai gantinya aplikasi memakai model "bawa kunci sendiri": pemilik sistem
mendaftarkan kunci API atas namanya sendiri (MapTiler, Esri ArcGIS, Mapbox,
atau sumber ubin miliknya sendiri). Tanpa kunci, aplikasi tetap berjalan penuh
memakai Peta Grid yang digambar sendiri di perangkat — tanpa server pihak mana
pun, tanpa biaya, tanpa ketentuan tambahan.


LAYANAN OPSIONAL YANG DIPANGGIL SAAT DIPAKAI
=============================================

  - Google Gemini API — hanya aktif bila pemilik sistem mengisi API Key
    miliknya sendiri. Tunduk pada ketentuan layanan Google.

  - api.qrserver.com (goQR.me) — membuat gambar QR kartu warga. Gratis,
    tanpa jaminan ketersediaan. Bila layanan ini tidak dapat dijangkau,
    aplikasi menampilkan token kartu dalam bentuk teks.

  - Google Workspace (Sheets, Drive, Apps Script) — berjalan di akun Google
    milik pelanggan sendiri, tunduk pada ketentuan Google.

  - WhatsApp (wa.me) — hanya membuka tautan; tidak ada data yang dikirim ke
    pihak WargaNet.


DATA PELANGGAN
==============

Seluruh data tersimpan di Google Sheets pada akun Google milik pelanggan.
Penyedia aplikasi tidak menyimpan salinan data pelanggan.
